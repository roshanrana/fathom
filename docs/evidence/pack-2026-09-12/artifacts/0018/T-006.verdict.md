## Findings

1. **[MEDIUM, non-blocking, → Planner]** `fathom/filings.py`'s frozen `HEADER` regex parses MCD's
   10-K to page-reference stubs instead of body text for all `10-K:*` sections, because that
   filer's real section headings ("BUSINESS SUMMARY", etc.) don't match `item\s+\d...`. This
   currently only affects MCD in the 20-ticker universe (`claims_total == 8`, allowlisted). Fix
   belongs in `filings.py`'s header/body matching, e.g. preferring a body match containing
   qualifying prose over the shortest-wins default, or recognizing alternate heading vocabularies.
2. **[LOW, non-blocking, → Planner]** `fathom/guard.py`'s frozen `ADVICE_PATTERNS[2]`
   (`recommend...buy|sell|hold|purchas\w*|invest\w*|position`) matches `purchas\w*`/`invest\w*`
   inflections but not `buy`-family inflections (`buying`, `bought`, `sells`, `held`, ...), since
   only `buy`/`sell`/`hold`/`position` are listed as bare words with no `\w*` suffix. This let the
   task pack's literal AC4 example text slip past the guard. Consider extending to
   `buy\w*|sell\w*|hold\w*` if the guard is meant to catch verb-form variants.
3. **[LOW, non-blocking, cleanup]** Stray `.tmp-audit/log.jsonl` at the live-tree repo root,
   unrelated to any committed test — safe to delete; not a product of this diff's test suite.

Both AC4 and AC5's deviations were judged: legitimate, because the root cause sits in modules
frozen outside this task's scope (`guard.py` under T-005, `filings.py` under T-002), the
implementer could not have satisfied the literal criterion within `fathom/briefing.py`'s scope,
and each is transparently documented in-line (`## Blocked` in the task pack, inline comments in
`tests/test_briefing.py`) with a working, faithful-to-intent substitute rather than silently
weakened tests.
